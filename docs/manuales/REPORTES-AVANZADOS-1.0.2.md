# Reportes avanzados 1.0.2

Esta versión reorganiza el visor de reportes sin cambios de servidor ni migraciones.

1. En **Administración → Módulos**, valida e instala `advanced-reports-1.0.2.zip`.
2. Reinicia el servidor y vuelve a abrir el POS en cada terminal para cargar el ensamblado de escritorio.
3. Abre **Reportes**. La ventana ocupa el área disponible y la tabla ya no comparte espacio con una barra lateral.
4. Usa **Vistas personales** para elegir o guardar una configuración. Usa **Columnas (N)** para mostrar u ocultar columnas. Las columnas visibles se mantienen como las que se exportan a CSV/XLSX.

El orden de las columnas se cambia arrastrando sus encabezados. No se modifica la consulta autorizada ni los datos del servidor.
